# CR7: The Road to 1000 Goals Prediction
This project uses data science and machine learning techniques to predict when Cristiano Ronaldo will hit the historic milestone of 1,000 career goals. By analyzing historical performance, scoring rates, and age-related trends, this model estimates the timeline for one of football's greatest achievements.
# 📊 Project OverviewThe goal of this repository is to answer the question: “When will CR7 score his 1000th goal?” We analyze:
Historical Scoring Data: Goals per season across different leagues (La Liga, Premier League, Serie A, SPL) and national team appearances.
Scoring Rate ($G/G$): How his goals-per-game ratio has evolved over time.
Predictive Modeling: Using regression analysis and time-series forecasting to project future goal tallies.
# 📁 Repository Structure
CR_7 1000th goal prediction/: Contains the core logic and datasets.deepl-py.ipynb: The primary Jupyter Notebook featuring data cleaning, visualization, and the prediction model.README.md: Project documentation.
